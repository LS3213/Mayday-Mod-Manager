# 存档管理 0.6.55：房主单装与混合联机存档（测试版）

作者：**lansi** · QQ 交流群：**974731412**

适用于 Windows x64 版 Mayday Airways Demo，基于 Demo 0.14.11 开发确认。管理器继续使用 **1.2.6**，无需重装。

## 本次更新

**不再要求全员安装存档模组。**

- **只有房主安装：** 正常保存飞机、乘客、资金、机场物品等公共世界状态和房主个人进度。
- **混合安装：** 只采集已安装同版并完成同步的玩家个人快照，未安装、版本不同或尚未识别的玩家跳过本次个人状态，不阻止房主保存。
- **手动和自动保存一致：** 六个手动档及机场结算自动档均使用新规则。界面显示记录的个人进度份数及本次跳过人数，份数可包含以前保留的离线记录。
- **保留原个人记录：** 原玩家暂时没装回来时按游戏原生方式加入，不替换其当前背包，旧个人记录继续保留；装好同版并同步后才恢复自己的原槽位物品，并跟随当前房主归队。
- **未安装者离场：** 不为其建立个人档或清空背包，沿用游戏原生断线处理。

参与名单按保存开始时已识别的玩家确定。需要保留个人进度的好友请安装 **0.6.55** 并等待同步后再保存；未参与期间新增的背包、穿戴及本人动作不承诺保存。公共世界里已经放下的物品仍按世界物品保存。

**已参与者真正同步失败或超时时，会提示失败并保留旧档。** 不会静默把坏快照当作“未安装”后覆盖原档。采集或恢复期间仍会短暂同步暂停。

## 安装与升级

首次使用先安装 [模组管理器 1.2.6](https://github.com/LS3213/Mayday-Mod-Manager/releases/tag/manager-v1.2.6)，再通过「添加 MOD」导入附件 **Mayday-Save-0.6.55.maydaymod**，启用后重启。GitHub 的 Source code ZIP 不是安装包。

已有旧包：**手动保存 → 备份实际使用的 saves 目录 → 管理器删除旧包 → 重启清理 → 添加新版 → 启用 → 再重启。** 只有需要记录个人进度的好友需一起更新到同版，未安装好友仍可正常加入。

包 ID `mayday-save`、存档格式版本、目录、六手动档＋一个结算自动档保持不变，升级不主动删除存档，无需迁移。优先目录为 `%USERPROFILE%\AppData\LocalLow\Lyngo Games\Mayday Airways\saves`，不可写时使用游戏目录 `UserData\saves`。没有新增前置依赖、玩法、热键或设置开关。

离线记录仍需随后手动保存或机场结算自动保存才能写盘，没有退出自动保存或云同步。以前漏记并覆盖掉的数据无法凭空补回。继续包含 [0.6.54 的乘客、行李、朝向及机场历史修复](https://github.com/LS3213/Mayday-Mod-Manager/releases/tag/mayday-save-v0.6.54)。

## 实际验证范围

已用三个独立原生游戏进程建立实际 LAN 房间：房主和一个客户端加载本版，第三客户端只有自动联机测试驱动，没有存档模组及其协议。

通过房主单装、三人混合安装、版本不符、手动／结算自动保存；确认收集参与者本人客户端体力及背包，未安装者个人记录不写入。故意丢弃已参与者快照时，旧档保持不变并释放暂停。另确认未安装者离开时保留原生背包处理，老玩家不装回来不会被替换背包或阻止保存，之后装好同版可按原身份恢复原槽位物品，全部已安装时的保存也正常。

测试采用模拟稳定身份、造物、体力设值及原生结算入口的阶段夹具；不是人工完整游玩、真实 Steam 多账号或公网验证。**仍属测试版，未遍历全部多人事件、延迟和第三方模组组合。** 本版不宣称修复此前部分环境的原生退出异常。
