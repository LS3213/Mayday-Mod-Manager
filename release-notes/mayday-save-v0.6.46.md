# 存档管理 0.6.46：机场结算自动档与喷漆恢复（测试版）

作者：**lansi** · QQ 交流群：**974731412**

适用于 Windows x64 版 Mayday Airways Demo。本版同时包含尚未单独公开发布的 0.6.45 喷漆修复；管理器继续使用 1.2.6。

## 本次更新

- 新增一个独立「自动存档」，每次机场结算完成、进入周转阶段后更新最新一份；六个手动档独立保留。
- 自动档位于面板顶部，支持主菜单单人／联机读取和确认删除。游戏内显示「结算后更新」，不提供手动覆盖；删除后下次结算重新生成。
- 自动保存沿用整局快照及队友本人动作采集。初始化或同步暂未就绪时等待，失败会提示并保留上一份自动档；重复报告或读取已结算存档不会再次触发。
- 补齐机身各面板的主色、点缀色、喷到一半的颜色过渡与覆盖进度，恢复后可继续原生喷涂；好友晚加入补同步初始喷涂外观。
- 散落喷漆罐纳入保存范围，喷漆罐的余量、选色及主色／点缀色模式随物品恢复。

## 安装与升级

先安装 [模组管理器 1.2.6](https://github.com/LS3213/Mayday-Mod-Manager/releases/tag/manager-v1.2.6)，再通过「添加 MOD」导入本页附件 **Mayday-Save-0.6.46.maydaymod**，启用并重启。GitHub 的 Source code ZIP 不是安装包。

已有旧包时：**手动保存 → 备份实际使用的 saves 目录 → 在管理器删除旧包 → 重启完成清理 → 添加新版 → 启用 → 再重启。** 主机和所有好友都要更新到同一版本 **0.6.46**。无需重新安装管理器。

包 ID、数据目录和现有存档格式版本不变，原六个手动档无需搬迁；自动档单独写入 `autosave.json`，覆盖时保留上一份有效备份。旧档没有记录的喷漆／动作数据无法补回，请在正确的游戏现场重新保存。

## 使用与确认范围

主菜单「存档管理」选择手动档或自动档读取，再选单人或联机。机场结算后自动档更新；航班途中退出前仍需手动保存。没有云同步，也没有新增模组热键。

本机隔离原生游戏已确认喷漆保存、冷启动读取、重存、继续喷涂及 LAN 晚加入外观同步；结算自动档已确认单人及 LAN 双人连续结算、队友动作、手动档不变、备份与删除、失败保留上一份，以及冷启动读取后资金和周转状态保持、不重复结算。七行原生面板与自动档两种读取入口已核对。

仍属测试版，**真实 Steam 双账号／公网及所有多人事件组合未遍历验证**。卡门／疏通、发动机维修／点火中途的部分状态、部分物品与机场设施、独立事件等仍有覆盖缺口。此前部分环境中的退出异常未定位，本版不宣称已修复。不要将上述确认范围理解为所有内容已完整恢复。

详见 [使用说明](https://github.com/LS3213/Mayday-Mod-Manager/blob/main/mods/mayday-save/README.md)。附件提供模组包及 SHA-256 校验文件。
