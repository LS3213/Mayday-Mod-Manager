# 存档管理 0.6.54：乘客、行李与机场历史保存修复（测试版）

作者：**lansi** · QQ 交流群：**974731412**

适用于 Windows x64 版 Mayday Airways Demo；基于 Demo 0.14.11 开发确认。管理器继续使用 **1.2.6**。本次累计包含公开版 0.6.52 之后的 **0.6.53 和 0.6.54** 修复。

## 修复内容

- **登机乘客及行李漏记：** 原来依赖飞机某一帧的触地标记识别登机现场；标记短暂为假时会遗漏排队乘客、后续待生成名单及机场行李。现在按实际登机流程采集，并保留飞机当时的运动状态。
- **到达／下机／周转漏记：** 同样移除对瞬时触地标记的依赖，保留正在离机、等行李和离场的乘客、机场行李及对应阶段。
- **乘客反坐：** 读取时同步恢复房主端新生成乘客模型的旋转，避免保留生成时的排队朝向。
- **空中保存报「赌场所属机场尚未记录」：** 地勤／赌场可能在飞机落地前移到目的地，现在同步记录对应现场及机场关联，避免阻断保存。
- **空中读档后重存丢失历史筹码：** 机场现场尚未恢复时保留历史散落筹码；回访恢复后重新采集真实现场，保留最新数量，已移除的筹码不会再次出现。

继续包含 0.6.52 的 P6～P10、队友跟随当前房主归队及离线个人物品保留。六个手动档＋一个机场结算自动档、菜单操作和无模组热键方式保持不变，没有新增玩法或前置依赖。

## 安装与升级

首次使用先安装 [模组管理器 1.2.6](https://github.com/LS3213/Mayday-Mod-Manager/releases/tag/manager-v1.2.6)，再通过「添加 MOD」导入本页附件 **Mayday-Save-0.6.54.maydaymod**，启用并重启。GitHub 自动生成的 Source code ZIP 不是安装包。

已有旧包：**手动保存 → 备份实际使用的 saves 目录 → 管理器删除旧包 → 重启清理 → 添加新版 → 启用 → 再重启。** 主机与所有好友均需更新到 **0.6.54**，管理器无需重装。

包 ID `mayday-save`、存档目录、JSON 格式版本及档位布局不变，升级不主动删除存档，无需搬迁。优先目录为 `%USERPROFILE%\AppData\LocalLow\Lyngo Games\Mayday Airways\saves`，不可写时使用游戏目录的 `UserData\saves`。

**已有完整名单及物品数据的档位可以继续读取；此前已漏记并覆盖成空名单的数据无法凭空补回。** 更新前请备份，必要时从尚含完整数据的档位继续。

队友归队仍跟随房主当前所在的飞机或机场，保留个人物品，不回旧位置。离线记录需随后手动保存或机场结算自动保存才写盘，没有退出自动保存或云同步。

## 定向验证范围

0.6.53 已确认：登机初期保留已生成乘客和待生成名单，新进程读取后继续生成与重存；已落座乘客及行李重建、房主端模型朝向；空中目的地赌场保存及新进程读取。

0.6.54 已确认：到达、下机、周转三种阶段分别在瞬时未触地条件下保存，新进程读取后保留 **6 名乘客、2 件行李**及阶段，重存并放行原生更新。另确认空中读档后连续重存保留历史筹码身份与余量；机场回访后生成原筹码，数量改变及真正移除均按实际现场保留。

测试使用隔离原生游戏进程和独立测试存档，包含阶段设值、瞬时触地标记及快速移位夹具。读取核对期间暂缓测试副本原生离场流程，再放行更新；不是完整手飞或真实 Steam 双账号／公网复测。**仍属测试版，不保证所有随机组合、所有多人事件及第三方模组私有状态均已无遗漏。** 先前部分环境的原生退出异常，本版不宣称修复。
