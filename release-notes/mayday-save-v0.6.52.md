# 存档管理 0.6.52：恢复补全与队友跟随归队（测试版）

作者：**lansi** · QQ 交流群：**974731412**

适用于 Windows x64 版 Mayday Airways Demo；本轮基于 Demo 0.14.11 开发确认。管理器继续使用 **1.2.6**，无需重新安装。本次累计发布自公开版 0.6.46 之后的更新。

## 0.6.52：离线物品保留与跟随房主归队

- 按 Steam 身份保留各自的背包、四格快捷栏、手持栏、物品数量／余量与已支持的专属状态，包含救生衣和黏鞋等已接入穿戴物。
- 正常断开前采集最新个人物品；修复成功归队后再次离线，后续存档遗漏该玩家记录的问题。缺席队友记录继续随本局保存，其他账号不会继承。
- 原队友归队到房主**当前**所在的飞机或机场附近，不回到旧机场、旧空中坐标或旧座位。清理旧攀爬、安全绳、倒地动作过程、点火长按、Boss 抓持、推车、广播、驾驶及油枪持有等场景关联，需要时重新操作。
- 房主本人沿整局存档恢复。已产生的世界结果与资金不因归队重复结算。

**离线记录先留在本局内存，下一次手动保存或机场结算自动保存才写盘。** 没有退出自动保存；队友离线后房主准备结束游戏，请先手动保存。记录属于当前局／当前档位，不是跨档位的全局物品仓库。

## 安装与升级

首次使用先安装 [模组管理器 1.2.6](https://github.com/LS3213/Mayday-Mod-Manager/releases/tag/manager-v1.2.6)，再在「添加 MOD」导入本页附件 **Mayday-Save-0.6.52.maydaymod**，启用并重启。Source code ZIP 不是安装包。

已有旧包：**手动保存 → 备份实际使用的 saves 目录 → 管理器删除旧包 → 重启清理 → 添加新版 → 启用 → 再重启。** 主机与所有好友需一起更新到 **0.6.52**。

包 ID `mayday-save`、数据目录、存档格式版本不变，不主动删除旧档，无需搬迁。旧档未记录的物品、维修、设施或事件状态无法补回，请在现场正确时重存。存档目录优先为 `%USERPROFILE%\AppData\LocalLow\Lyngo Games\Mayday Airways\saves`，不可写时使用游戏目录 `UserData\saves`。

## 实际确认范围

P6～P10 分阶段完成隔离原生进程保存、新进程读取／重存／原生继续，以及本机 LAN 双进程定向验证。赌场与 Boss 已在当前 Demo 确认原生事件入口。

0.6.52 另确认：不同身份物品隔离、比上次保存更新的物品余量、四格与手持栏、救生衣／黏鞋、重复离场归队、飞机内和跨机场跟随；两端全新进程读取后跟随房主新位置；离线记录进入结算自动档且手动档不变。

测试使用模拟稳定身份，含快速移位、造物和阶段设值，并非真实 Steam 双账号／公网测试或人工手飞所有遭遇。**仍属测试版，未遍历全部装备、第三方模组和多人事件组合，不能宣称游戏每个状态均无遗漏。** 此前部分环境的原生退出异常未定位，本版不宣称修复。
