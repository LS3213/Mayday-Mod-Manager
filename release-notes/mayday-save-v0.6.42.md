# 存档管理 0.6.42（测试版）

作者：lansi · QQ 交流群：974731412。

## 安装与使用

先安装 [模组管理器 1.2.6](https://github.com/LS3213/Mayday-Mod-Manager/releases/tag/manager-v1.2.6)，再下载本页附件 **Mayday-Save-0.6.42.maydaymod**。在游戏「MOD 管理」中添加、启用并重启。不要将 Source code ZIP 当成模组包。

- 游戏中从机长／暂停菜单打开「存档管理」，选择六个独立档位之一手动保存。
- 主菜单「存档管理」选择档位读取，再选择单人或 Steam 好友房间模式。原来的「开始游戏」仍然开新局。
- 联机读取后由读档者担任主机，使用游戏原有「邀请好友」。保存由主机操作。

已覆盖飞机与飞行状态、经营升级、座椅、物品、行李、乘客、天气、机场现场和结算等主要整局状态。[完整说明与存档目录](https://github.com/LS3213/Mayday-Mod-Manager/blob/main/mods/mayday-save/README.md)。

## 升级与注意事项

先手动保存并备份 `saves`，在管理器删除旧包、重启，再添加新版、启用并重启。存档在独立数据目录，正常删包不会主动删除它们；存档界面「删除档位」会同时删除主档与备份。

**没有自动存档和云存档。** 请在退出前手动保存。仍属测试版，不能保证所有随机情况、其他模组组合及未来游戏版本都完整恢复。

联机目前以主机世界恢复为主；原队友身份、背包和中途动作完整续接尚未完成，第二个 Steam 账号的实际好友加入尚未完成验证。

部分测试环境出现过退出游戏时原生异常退出，原因仍在排查，不能排除模组、加载器或游戏退出流程的影响。

附件 `SHA256SUMS.txt` 可用于核对下载内容。
