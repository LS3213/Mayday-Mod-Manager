适用于 Windows x64 版 Mayday Airways Demo。推荐使用模组管理器 1.2.6。安装包独立于管理器，包 ID 为 `mayday-save`。

## 使用方法

1. 在「MOD 管理」中添加 `Mayday-Save-0.6.42.maydaymod`，点击启用，重启游戏。
2. 开始自己的游戏会话，打开机长／暂停菜单，点击左侧「存档管理」。该按钮位于「邀请好友」下方、「离开游戏」上方；单人模式会跟随可见按钮排列。
3. 选择六个档位中的一个手动保存。覆盖已有档位需要再次确认。
4. 下次从主菜单「开始游戏」右侧的「存档管理」选择档位并点「读取」，再选择「单人读取」或「联机读取」。原来的「开始游戏」仍然开新局。
5. 删除档位也需要再次确认；删除会同时移除该档位的主档与备份。

没有额外模组热键，通过菜单完成操作。结果报纸和游戏结束提示中也保留存档入口。空档、无法读取及备份恢复会在列表标明。

## 联机读取

从 Steam 启动并保持在线，选择「联机读取」，会以当前读取者为主机创建 Steam 好友房间。恢复后使用游戏原有暂停菜单中的「邀请好友」。Steam 未就绪时按钮不可用；建房失败不会悄悄改成单人模式。

**目前以主机整局世界恢复为主。** 原队友身份、背包、中途动作和断线重连的完整续接尚未完成。已检查建房与原生邀请入口，但未完成另一台电脑／第二个 Steam 账号的实际好友加入验证，请勿将其理解为完整多人续档。

联机保存由主机操作；加入别人房间的玩家不能代替主机保存整局。其他模组的联机要求仍以各自说明为准。

## 存档位置与备份

优先目录：

```text
%USERPROFILE%\AppData\LocalLow\Lyngo Games\Mayday Airways\saves
```

该位置不可写时使用游戏目录下的 `UserData\saves`。文件为 `slot-1.json` 至 `slot-6.json`；覆盖时保留上一份有效内容为 `.bak`。主档损坏或缺失且备份可读时，界面会标记备份恢复。

**没有自动存档、云同步或自动跨电脑迁移。** 开新局、退出会话或退出游戏不会自动改写档位。请手动保存并在更新前复制整个实际使用的 `saves` 目录。

管理器删除本模组不会主动删除独立存档；存档界面「删除档位」会删除对应主档和备份。未来格式／游戏版本变化可能影响读取兼容性。
