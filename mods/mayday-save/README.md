## 0.6.54 本次修复

- 修复登机、到达、下机和周转期间，飞机瞬时未触地时漏记乘客、待生成名单及机场行李。
- 修复读取后房主端乘客模型保留生成时朝向、出现反坐。
- 修复地勤／赌场提前移到目的地时，空中保存报「赌场所属机场尚未记录」。
- 修复空中读取后，机场现场尚未恢复就再次保存，导致历史散落筹码变成空；回访后按真实现场更新数量和移除结果。

本版包含 0.6.53 与 0.6.54 的修复。已有完整名单的档位可继续读取；旧版已漏记并覆盖成空名单的数据无法凭空补回，单纯升级无法重建缺失的乘客和行李。

## 使用方法

1. 在「MOD 管理」添加 `Mayday-Save-0.6.54.maydaymod`，启用后重启游戏。
2. 开始游戏，打开机长／暂停菜单左侧「存档管理」，位于「邀请好友」下方、「离开游戏」上方；单人模式跟随可见按钮排列。
3. 选择六个手动档中的一个保存，覆盖需再次确认。顶部「自动存档」每次机场结算完成、进入周转后更新最新一份，不占用手动档。
4. 下次在主菜单「开始游戏」右侧的「存档管理」选择档位，再选择「单人读取」或「联机读取」。原来的「开始游戏」仍然开新局。
5. 删除档位需确认，同时删除主档和备份。自动档可读取或删除，不可手动覆盖；删除后下次机场结算重新生成。

没有模组热键，均通过菜单操作。结果报纸和游戏结束提示中也保留入口。空档、不可读取和备份恢复会在界面标明。

自动档仅在结算后更新；初始化或联机同步未就绪时等待，失败提示并保留上一份。重复打开结算或读取已结算存档不会再次触发。**开新局、离开和退出本身不保存，航班途中退出前请手动保存。**

## 联机归队

「联机读取」以读取者为房主创建 Steam 好友房间，恢复后使用原生「邀请好友」。从 Steam 启动并保持在线；建房失败会提示。保存整局由主机执行，队友不能替主机保存。

0.6.52 按 **Steam 身份**保留各自的背包、四格快捷栏、手持物与已支持的穿戴装备。原队友回来时在**房主当前的飞机或机场附近**归队，不回到旧位置，也不接回旧座位、攀爬、安全绳或 Boss 抓持等场景动作。房主本人仍按整局存档恢复。

正常断开前采集最新个人物品，反复离线也更新；队友缺席时，主机后续保存继续保留记录。**离线记录先在本局内存中，手动保存或机场结算后才写盘**，没有退出自动保存。记录属于本局／当前档位，不跨档共享。同名不同账号不继承物品，没有记录的新玩家走原生加入流程。

保存会收集在线队友状态并短暂停止房间推进，无法收齐或版本不一致时提示失败并保留旧档。[完整联机规则与验证范围](../../docs/save-multiplayer.md)。

## 存档位置与升级

优先目录：

```text
%USERPROFILE%\AppData\LocalLow\Lyngo Games\Mayday Airways\saves
```

不可写时使用游戏目录的 `UserData\saves`。手动档为 `slot-1.json` 至 `slot-6.json`，自动档为 `autosave.json`；覆盖保留上一份有效内容为 `.bak`。主档缺失或损坏且备份可读时，标记备份恢复。没有云同步或自动跨电脑迁移。

更新前先手动保存、退出并复制实际使用的整个 `saves` 目录。通过管理器删除旧包 → 重启清理 → 添加新版 → 启用 → 再重启。管理器保持 1.2.6，无需重新安装；所有好友一起更新存档模组。

本次包 ID、目录、存档格式版本与六手动＋一个自动档不变，无需搬迁。删除模组不会主动删除独立存档，存档面板「删除档位」会删除主档和备份。旧档未记录的数据无法补回，应在现场正确时重新保存。详见 [升级说明](../../docs/installation.md)。
