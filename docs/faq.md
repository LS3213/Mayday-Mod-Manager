# 常见问题

## 下载哪个文件？

新玩家先下载管理器安装 ZIP，解压到游戏根目录；功能模组下载 `.maydaymod` 后从游戏「添加 MOD」导入。GitHub 自动生成的 Source code ZIP 不是安装包。

## 需要另外装加载器或 .NET 6 吗？

管理器安装包自带加载器和 .NET 6 运行时。玩家无需安装 .NET SDK。已有其他加载环境时需核对版本，不要重复混装。

## 首次启动为什么比较慢？

公开包没有包含其他机器生成的游戏互操作程序集。加载器需要在本机生成，并可能下载生成依赖，请保持联网；游戏更新后可能重新生成。异常时查看 `MelonLoader/Latest.log`。

## 启用后为什么没有立刻出现功能？

需要重启游戏。区分界面的「本次加载状态」与「下次启用状态」。新导入的包默认关闭。

## 可以直接导入旧版综合 MOD 压缩包吗？

不能仅凭 ZIP 扩展名判断。包需符合 manifest 及目录规范，不能夹带加载器和旧菜单外壳。未适配的包应由其作者整理，不要反复尝试覆盖安装。

## 为什么新版包提示 ID 已存在？

当前没有直接覆盖升级。先删除旧包并重启，再添加新版、启用并重启。更新前备份该模组的数据。

## 删除存档模组会丢档吗？

不会主动清理它在独立 `saves` 目录里的文件。但在存档界面删除档位会同时删除主档和 `.bak`。新版本是否能读取旧格式应看版本说明，不等于文件是否还在。

## 能完整恢复所有队友吗？

0.6.55 只记录房主及已安装同版、完成同步的队友个人进度，未参与者不阻止保存。按 Steam 身份保留背包、快捷栏与已支持装备；参与恢复的原队友跟随房主当前所在的飞机或机场，不回旧位置。真实 Steam 多账号／公网及所有协作事件组合仍待验证，详见 [联机说明](save-multiplayer.md)。

## 只有房主装，其他人没装也能存吗？

可以，从 **0.6.55** 起手动档和结算自动档都支持混合安装。房主保存公共世界与自己的进度；其他未装、版本不同或尚未同步的玩家跳过本次个人快照。要保存个人进度的好友安装同版并等待同步即可。已参与者真正同步超时仍提示失败并保留旧档。

## 队友离线很久再回来，物品会丢吗？

参与同步者正常断开前采集最新个人物品，反复离线也更新；缺席期间主机继续保存会保留其本局记录，不会分配给同名的其他 Steam 账号。暂时没装模组回来时不替换当前背包，旧记录保留，重新装好同版并同步后才恢复；未参与期间的新个人变化不承诺保存。离线记录先留在内存，之后仍需手动或机场结算保存写盘，退出本身不保存；记录不跨档位共享，旧档缺失数据无法补回。

## 登机／下机读档后乘客和行李丢失、乘客反坐怎么办？

请更新到 **0.6.55** 并重启，需要保存个人进度的好友一起更新。包含 0.6.54 的登机／到达／下机／周转漏记、房主端模型朝向、空中赌场报错及历史筹码修复。已有完整数据的档位可继续读取，旧版已漏记并覆盖掉的数据无法凭空补回。查看 [修复范围](../release-notes/mayday-save-v0.6.54.md) 和 [新版混合联机规则](../release-notes/mayday-save-v0.6.55.md)。

## 能自动更新或下载其他模组吗？

当前不能。仓库是发布与文档入口，管理器仍由玩家手动导入文件。未来收录其他模组不等于客户端已具有在线商店或自动更新功能。

## 有自动存档吗？

有一个独立机场结算自动档，每次结算完成后更新最新一份，六个手动档独立保留。自动档可以读取或确认删除，失败时保留上一份；0.6.55 与手动保存一样允许未安装好友在房间内，只采集已同步参与者的个人进度。没有定时、退出自动保存或云同步，航班途中退出前请手动保存。

## 飞机喷漆会保存吗？

0.6.46 包含 0.6.45 的喷漆修复，保存机身主色／点缀色、喷到一半的颜色过渡和覆盖进度，以及喷漆罐的余量和模式。旧档从未记录的喷漆无法补回，需要在正确的游戏现场重新保存。
