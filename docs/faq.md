# 常见问题

## 下载哪个文件？

新玩家先下载管理器安装 ZIP，解压到游戏根目录；功能模组下载 `.maydaymod` 后从游戏「添加 MOD」导入。GitHub 自动生成的 Source code ZIP 不是安装包。

## 需要另外装加载器或 .NET 6 吗？

管理器安装包自带加载器和 .NET 6 运行时。玩家无需安装 .NET SDK。已有其他加载环境时需核对版本，不要重复混装。

## 首次启动为什么比较慢？

公开包没有包含其他机器生成的游戏互操作程序集。加载器需要在本机生成，并可能下载生成依赖，请保持联网；游戏更新后可能重新生成。异常时查看 `MelonLoader/Latest.log`。

## 启用后为什么没有立刻出现功能？

需要重启游戏。区分界面的「本次加载状态」与「下次启用状态」。新导入的包默认关闭。

## 可以直接导入旧版综合 MOD 压缩包吗？

不能仅凭 ZIP 扩展名判断。包需符合 manifest 及目录规范，不能夹带加载器和旧菜单外壳。未适配的包应由其作者整理，不要反复尝试覆盖安装。

## 为什么新版包提示 ID 已存在？

当前没有直接覆盖升级。先删除旧包并重启，再添加新版、启用并重启。更新前备份该模组的数据。

## 删除存档模组会丢档吗？

不会主动清理它在独立 `saves` 目录里的文件。但在存档界面删除档位会同时删除主档和 `.bak`。新版本是否能读取旧格式应看版本说明，不等于文件是否还在。

## 能完整恢复所有队友吗？

目前支持以 Steam 好友房间方式读取主机整局世界，原队友身份、背包和中途动作完整续接尚未完成；实际好友加入仍需更多双机验证。保存由主机操作。

## 能自动更新或下载其他模组吗？

当前不能。仓库是发布与文档入口，管理器仍由玩家手动导入文件。未来收录其他模组不等于客户端已具有在线商店或自动更新功能。
