# 安装、升级与卸载

适用于 Windows x64 版 Mayday Airways Demo。作者：lansi；QQ 交流群：974731412。

## 首次安装管理器

1. 在 Steam 库中右键游戏 →「管理」→「浏览本地文件」，找到包含 `MaydayAirways.exe` 的目录。
2. 退出游戏，下载管理器 Release 中的 `Mayday-MOD-Manager-1.2.6.zip`，将内容解压到该目录。不要额外套一层文件夹，也不要把整包导入「添加 MOD」。
3. 确认 `version.dll` 与游戏 EXE 同级。包内包含加载器和 .NET 6 运行时，不要求玩家安装 .NET SDK。
4. 从 Steam 启动。公开安装包不携带本机生成的游戏互操作程序集；首次启动加载器会生成这些内容，可能耗时较长，并可能需要联网下载生成依赖。
5. 主菜单「设置」右侧出现「MOD 管理」，打开后可看到标题版本。初次安装没有预装任何功能模组。

如果已有 MelonLoader 或其他注入加载器，请先核对其版本和同名文件。不要盲目混装或覆盖自己的配置。游戏版本变化后，生成过程与模组兼容性也可能受影响。

## 安装、关闭与删除功能模组

1. 下载模组 Release 的 `.maydaymod` 文件，或符合本仓库规范的 `.zip`。
2. 在游戏「MOD 管理」中点击「添加 MOD」并选择文件。
3. 新包默认关闭。点击「启用」，重启游戏后加载。
4. 关闭、删除同样需要重启。界面分别显示本次加载情况和下次启动状态。

包存放在 `游戏目录/Mods/MaydayPkg.<id>/`。管理器只处理经界面导入的包；手动安装的 DLL 仍由加载器处理。同一模组不要同时保留手动安装和管理器导入的副本。

删除包只清理该包的目录。存档管理的存档位于包目录以外，删除模组不会主动清除它们。其他作者如果把数据写在自己的包目录里，删除包可能同时删除那些数据，请遵循各模组说明。

## 更新管理器

先手动保存并退出游戏，按目标版本 Release 的说明覆盖指定文件。不要为了升级删除整个 `Mods`、`UserData` 或存档目录。

- **1.2.2～1.2.5 → 1.2.6：** 从新安装包取出 `Mods/Mayday.PackageManager.dll`，覆盖同名文件即可。
- **1.2.0 / 1.2.1 → 1.2.6：** 还需覆盖 `MelonLoader/net6/MelonLoader.dll`。
- **1.0.0 / 1.1.0：** 退出游戏，将旧管理器的 `Mods/Mayday.ModMenu.dll` 移出游戏目录，再更新管理器 DLL。其他加载器文件按实际安装情况核对。

已导入的包目录与启用状态需要保留。旧安装包中的生成缓存无需从公开包补回。

## 更新功能模组

当前管理器不支持同 ID 的直接覆盖导入，也不会自动联网更新。

**手动保存 → 备份数据 → 在管理器删除旧包 → 重启完成清理 → 添加新包 → 启用 → 再重启。**

存档管理目前为 **0.6.54**，管理器仍使用 **1.2.6**；主机和所有好友需一起更新存档模组。本版累计包含 P6～P10 的恢复补全及离线玩家物品保留／跟随房主归队。六个手动档和 `autosave.json` 保持原路径，包 ID 与存档格式版本不变，不需要搬迁数据。旧档没有记录的个人物品、设施或事件状态无法补回，请在现场正确时用新版重新保存。队友离线后的最新个人记录先留在本局内存，主机还需手动保存或完成机场结算，不能直接退出当作已经写盘。未来版本是否可读旧档，以对应 Release 为准。

0.6.54 累计包含登机／到达／下机／周转乘客及行李漏记、乘客反坐、空中赌场关联报错与历史筹码重存修复。已有完整数据的档位可继续读取；此前漏记并覆盖掉的数据无法通过升级自动补回。详细范围见 [0.6.54 更新说明](../release-notes/mayday-save-v0.6.54.md)。

## 卸载与排查

只想停用功能模组，在管理器中关闭并重启即可。只想暂停整个加载器，可按 MelonLoader 自身方式禁用；彻底移除时，只移走确认属于本次安装的文件，保留自己的数据，不要误删游戏本体或其他加载器的文件。

默认不显示控制台，日志仍写入 `MelonLoader/Latest.log`。需要排查时可在 `UserData/Loader.cfg` 的 `[console]` 中设置 `hide_console = false` 后重启。

`disable_subfolder_load = false` 和 `disable_subfolder_manifest = false` 应保持默认值，管理器依赖这两个设置执行包的加载与关闭。
