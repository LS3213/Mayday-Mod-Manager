# 联机存档：0.6.46

## 玩家需要做什么

主机和好友都安装模组管理器提供的加载环境，再导入同版 `Mayday-Save-0.6.46.maydaymod`、启用并重启。管理器可继续使用 1.2.6。保存由主机执行，好友不需要自己创建同名存档。

让好友进入房间并等待初始化完成，然后由主机手动保存；机场结算后也会自动写入独立自动档。成功提示会显示机组人数。两种保存都会收集队友动作，收集动作快照及恢复队友动作时会短暂暂停房间推进与交互，确认完成后恢复；无法收齐、版本不一致或同步超时会明确提示，不覆盖原档位。

读档时主机选择「联机读取」，等世界恢复后使用游戏原生「邀请好友」。同一 Steam 身份的原队友重新加入后会接回自己的记录。未在档中的新玩家按原生加入流程进入，不会拿到同名原队友的状态。

## 远端动作恢复范围

| 类别 | 内容 |
| --- | --- |
| 体力与运动 | 体力、疲劳、冲刺计时、主动与外力速度、跳落、蹲身、打滑和眩晕等已有运动快照 |
| 攀爬 | 路线、支撑物、动作阶段、抓握位置、时间线与显示；按当前飞机／世界坐标重新定位 |
| 安全绳与装备 | 挂接、路径、爬绳阶段、相关拉拽数据、黏鞋及救生衣的本机动作状态 |
| 倒地与起身 | 物理身体、速度、旋转、骨骼与关节、睡眠状态、起身混合姿态与相关计时 |
| 其他个人状态 | 背包、快捷栏、位置朝向、座位、生死与视角，沿主机权威状态及客户端快照共同恢复 |

客户端只恢复本人的本机控制状态，不替主机生成道具或写其他玩家的网络状态。主机先恢复共享物品和座位，客户端等原生传送、物品与座位就绪后再接动作并回执，主机确认后统一释放房间暂停，避免短计时提前结束。观察者另行接回抓握与倒地显示。

## 验证范围

已用两个独立原生进程在本机 LAN 验证八个完整存读档循环：普通体力／跳落、座位上的体力、攀爬悬挂、攀爬拉起、飞机位移转向后的攀爬、安全绳、倒地中、起身中；每轮包含离房、重建会话、重新加入及动作继续。倒地数据覆盖 10 个物理骨骼、13 个关节。

还检查了未开启同步协议的主机与新版客户端连接超过 90 秒，未出现握手解析或断连错误。

上述八个动作循环在 0.6.44 交付时完成。0.6.45／0.6.46 本轮另用 LAN 双进程确认喷漆颜色与初始覆盖进度的晚加入同步、结算自动档收集两名机组及远端体力，以及自动档冷启动读取；未宣称本轮重新遍历所有既有动作组合。

测试使用模拟身份，不是真实第二个 Steam 账号；真实公网延迟、三人以上协作和所有特殊事件引用组合尚未遍历验证。本文描述已实现的动作采集与恢复能力，不保证所有游戏版本、所有其他模组组合都完全一致。旧档未采集的客户端数据不能补回，建议使用新版重存。
