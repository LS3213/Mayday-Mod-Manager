# 联机存档：0.6.54

## 安装与保存

主机和好友均安装 **0.6.54** 存档模组并启用、重启，管理器继续使用 **1.2.6**。保存由主机执行，好友无需创建同名档位。

好友进入房间并完成初始化后，主机可以手动保存；机场结算完成后也会更新独立自动档。保存时收集在线队友的本人状态，短暂停止房间推进与交互，成功后统一写盘并恢复。无法收齐、版本不一致或同步超时会提示失败并保留原档。

从主菜单选择「联机读取」，等世界恢复后使用原生「邀请好友」。需从 Steam 启动并保持在线。Steam 未就绪或建房失败时会提示，不会自动改成单人模式。

## 玩家身份与个人物品

按 **Steam 身份** 匹配记录，不按昵称、加入顺序或旧网络对象编号匹配。同名不同账号不会继承别人的物品；没有记录的新玩家沿原生流程加入。

正常断开前由主机采集该玩家最新的背包、四格快捷栏、当前手持栏、物品数量／余量及已支持的专属状态，救生衣与黏鞋等已接入穿戴物一并保留。玩家成功归队后再次离线，也会更新自己的记录。其他玩家继续游玩、手动保存或结算自动保存时，缺席队友的记录继续保留。

**离线记录先保存在本局内存，下一次手动保存或机场结算自动保存才写入档位。** 开新局、离开会话和退出不会自动保存。好友离线后主机准备结束游戏时，请先手动保存。

记录属于当前局／当前所读档位，不是跨档位的全局账号仓库。旧档未保存的物品和异常断连前未成功采集的数据不能凭空补回，也不代表支持所有服装皮肤或第三方模组私有数据。

## 归队位置：跟随当前房主

从 0.6.52 起，原队友恢复时以**房主此刻的位置**归队：房主在飞机中就回到当前飞机附近，房主已到另一机场就回到该机场的房主附近。不会回到几小时前的机场、空中坐标或旧座位。

归队保留个人物品和已支持的装备，清理旧的座位占用、攀爬、安全绳挂接、倒地动作过程、点火长按、Boss 抓持、推车、广播、驾驶和油枪持有等场景关联；需要操作时由玩家重新执行。已经产生的世界结果、资金及共享物品沿整局存档恢复，不因归队重新结算或重发奖励。

这是对早期版本“按旧现场接回远端动作”规则的调整。底层仍采集本人状态并使用确认流程，但归队以当前房主为准，不再接回过时的动作位置。**房主本人**仍沿整局存档恢复。

## 验证范围

0.6.53／0.6.54 针对登机、到达／下机／周转、房主端乘客朝向和机场历史筹码完成隔离原生新进程存读档、重存与定向回访确认；本轮没有重新进行真实 Steam 双账号／公网或所有联机组合测试。[本次修复与具体范围](../release-notes/mayday-save-v0.6.54.md)。

0.6.52 本机原生 LAN 双进程定向确认：两个不同身份的物品隔离；四格与手持栏、余量、救生衣／黏鞋；离线前比上次存档更新的物品；反复离场归队；飞机内和跨机场跟随；两端全新进程读取后房主再次移动，原队友仍在新位置归队；离线记录写入结算自动档，手动档不变。

P6～P10 另有隔离原生冷启动与 LAN 定向确认，覆盖维修、物品使用、设施、赌场和 Boss；这些阶段测试中的旧动作恢复结果，不代表 0.6.52 仍接回旧位置或旧挂接。

测试采用模拟稳定身份，包含快速移位、造物及阶段设值，不是真实第二个 Steam 账号或人工完整手飞所有事件。**真实 Steam 双账号／公网、多种延迟、全部穿戴装备和多人事件组合尚未遍历验证。** 仍属测试版，不能承诺所有状态和组合均无遗漏。
